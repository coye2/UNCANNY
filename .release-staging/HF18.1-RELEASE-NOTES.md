# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.1

HF18.1 is a focused launcher/install hotfix on top of HF18.

## Fixed

- Install/update no longer sits behind repeated full WMI process enumeration during target validation.
- The launcher now shows real preflight progress at 3%, 4%, 5%, 6%, and 7% instead of appearing frozen at 2%.
- The updater status button uses a wider compact layout with shorter **Up to date** / **Update ready** states.
- The launcher now uses the current full-color purple/green ELYSIUM emblem.

## Preserved

HF18 Universal API Bridge behavior, D3D11 native-Present stabilization, ELYSIUM rendering, Motion Guard/Ghosting Guard, Adaptive Realism, PCSX2, REVENANT and rollback remain preserved.
