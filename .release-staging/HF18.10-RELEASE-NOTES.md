# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.10

HF18.10 is a direct-D3D12 startup and resize stabilization hotfix based on two separate real-hardware failures: PCSX2 could open in Direct3D 12 but remain at **No Image / GPU 0% / FPS N/A**, and Spider-Man 2 could install successfully but fail to launch through the current DX12 runtime path.

## Universal direct-D3D12 startup stabilization

- Extends the long native-only startup/transition stabilization floor from protected D3D11 routes to direct D3D12.
- D3D12 receives 180 successful native Presents plus a 5-second post-transition native-only window before optional UNCANNY preprocessing can activate.
- Native Present remains authoritative and fail-open.
- This is route-wide behavior. The runtime contains no PCSX2 or Spider-Man executable-name exception.

## D3D12 ResizeBuffers / ResizeBuffers1 repair

- Before UNCANNY has acquired resources from a D3D12 swapchain, application resize calls pass straight through to the native DXGI implementation.
- UNCANNY no longer manufactures `DXGI_ERROR_WAS_STILL_DRAWING` during early D3D12 renderer bring-up just because the Present mutex is briefly busy.
- After UNCANNY has acquired D3D12 resources, resize uses the older safe contract: wait under the Present mutex, retire owned resources with bounded waits, then call the application's native resize.
- Resize success re-arms the native-only stabilization window before ELYSIUM / Feature-18 work resumes.

This specifically targets the failure class where installation is correct but the direct-DX12 renderer never reaches a usable image/presentation state.

## Preserved HF18.9 behavior

- Stray's working direct-D3D11 path is unchanged.
- The universal D3D11 current-frame safe floor remains active.
- PCSX2 remains explicitly configured for Direct3D 12 with `Renderer=15`.
- PCSX2's existing D3D12 / Feature-18 execution path is preserved; HF18.10 does not downgrade the emulator to D3D11.
- HF18.8 launch-state repair, legacy-wrapper migration, verified sidecar launch, Cloud Files support, transactional rollback, scanner/library fixes, Motion Guard and Ghosting Guard remain preserved.
