# UNCANNY HF18.11

This release fixes one specific D3D11 problem: the safety path from the earlier stability fixes was also keeping the neural route disabled forever.

HF18.11 keeps the safe startup behavior, but now lets neural resources warm up after the D3D11 route has been stable long enough.

## What changed

- direct D3D11 can promote into the neural path again
- the game still gets a protected native/current-frame startup first
- neural warmup stays off Present
- the riskier depth/temporal path stays disabled on the D3D11 safe route
- resize/fullscreen-style transitions reset the promotion window instead of carrying stale state forward

The current promotion window is 240 processed frames and at least 9 seconds after the last relevant DXGI transition.

## Still included

HF18.10's D3D12 startup/resize fix is unchanged.

PCSX2 still uses the Direct3D 12 `Renderer=15` route, and the current sidecar launcher, rollback, scanner/manual-add fixes, Motion Guard, Ghosting Guard and REVENANT are all preserved.
