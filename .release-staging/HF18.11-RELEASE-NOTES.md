# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.11

HF18.11 fixes a D3D11 bug left behind by the earlier hard-lock work.

The D3D11 safe path was protecting Present correctly, but it was also keeping the neural path disabled forever. A game could be running ELYSIUM normally while the neural route never actually had a chance to come online.

## What changed

Direct D3D11 now starts on the conservative current-frame path, then allows neural resources to warm up after the route has been stable long enough.

Current promotion window:
- 240 processed frames
- at least 9 seconds since the last relevant DXGI transition
- a healthy, advancing Present stream

The riskier direct-depth and temporal path is still deferred on this route. Resize, fullscreen and similar transitions reset the promotion window.

## Also in this build

- HF18.10 D3D12 startup/resize protection is unchanged.
- PCSX2 stays on Direct3D 12 with `Renderer=15`.
- The current sidecar launcher and old PCSX2-wrapper migration are preserved.
- Scanner/manual-add fixes, rollback, REVENANT, Motion Guard and Ghosting Guard are preserved.
