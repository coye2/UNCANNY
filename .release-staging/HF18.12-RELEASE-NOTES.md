# UNCANNY HF18.12

This one is focused on the three launch/runtime failures from current hardware testing.

## PCSX2

PCSX2 could get into gameplay, run for a few seconds, then hard-freeze right when the D3D12 path moved out of startup protection.

HF18.12 moves first-use D3D12 frame-processor setup off Present. Native Present keeps moving while UNCANNY prepares the D3D12 resources in maintenance instead of doing the heavy setup on the game thread.

D3D12 resize/resource retirement is also fail-fast now instead of waiting behind UNCANNY-owned GPU work.

PCSX2 stays on the same Direct3D 12 `Renderer=15` route.

## Cyberpunk / Spider-Man 2

Some modern targets were dying before a usable game process stayed up, then leaving a stale sidecar session behind.

HF18.12 adds a deferred startup attach route for non-PCSX2 executables that do not expose a static graphics API import. The game gets to establish native startup first, then UNCANNY attempts the runtime attach. If that attach cannot be confirmed, the game is left running instead of being killed by the optional runtime path.

Stale crashed sidecar ownership is also bounded and recoverable, so repeat launches should no longer get trapped behind `SESSION_ALREADY_TRACKED PID=0`.

## Preserved

HF18.11's staged D3D11 neural promotion is preserved.

The current launcher, rollback, scanner/manual-add, Motion Guard, Ghosting Guard, Adaptive Realism, REVENANT, and the verified sidecar architecture are preserved.
