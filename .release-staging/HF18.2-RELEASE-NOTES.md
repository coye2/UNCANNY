# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.2

HF18.2 fixes the remaining launcher/update UX and package-layout complaints reported after HF18.1.

## Launcher/update fixes

- Fixes post-install/update refresh crashes caused by older or freshly-scanned launcher records missing `InstalledBuildId`.
- Normalizes cached, manually-added, and newly-scanned game records to one schema before mutation.
- Replaces full-game-executable memory reads during target inspection with direct PE header/import-table reads.
- Keeps the existing bounded install/update process preflight from HF18.1.

## Branding fix

- The launcher now crops the emblem region from the full ELYSIUM artwork before displaying it.
- The badge uses normal aspect-ratio preservation and centered positioning instead of squeezing/cropping the full poster into the 54px box.

## Cleaner public ZIP

The public package root is now intentionally minimal:

- `UNCANNY.exe` remains the normal root entry point.
- PowerShell implementation is under `runtime\`.
- Maintenance command files are under `Tools\`.
- Root-level `.ps1` / `.cmd` clutter is rejected by the release gate.
- Every packaged PowerShell file under `runtime\` is parsed after extracting the final ZIP.

## Preserved

HF18 rendering, Universal API Bridge behavior, D3D11 native-Present stabilization, Motion Guard/Ghosting Guard, Adaptive Realism, WARP visual-quality validation, PCSX2, REVENANT, rollback, and source-protection boundaries remain preserved.
