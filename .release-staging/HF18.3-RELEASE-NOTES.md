# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.3

HF18.3 has been refreshed with the final polished launcher build.

## Launcher / installed-game crash

- Fixes the installed-game/library crash caused by StrictMode-fragile `.Path` and missing-property assumptions.
- Cached, manual, and installed-game records now resolve executable paths through guarded normalization.
- Missing legacy fields such as `Path`, `Exe`, and `InstalledBuildId` no longer tear down the launcher UI.
- Packaged `UNCANNY.exe` survived the Windows startup/ShowDialog smoke test.

## Branding

- Removes the synthetic SVG/vector-style launcher badge.
- Uses the official UNCANNY silver circular U emblem from the project Library as a tightly cropped PNG.
- No added text or fake redraw is used in the launcher badge.

## Clean EXE launch

- The native desktop launcher no longer starts PowerShell with `-ExecutionPolicy Bypass`.
- Startup uses the normal hidden, non-interactive bootstrap path.
- This does not disable or weaken Windows Defender/SmartScreen.

## Preserved

- Stale/unmarked Lucid preferences still migrate to Automatic/ELYSIUM.
- Explicit current `UserSelected=1` Lucid choices remain respected.
- HF18/HF18.2 rendering, Universal API Bridge, D3D11 stabilization, PCSX2, REVENANT, rollback, and the clean `runtime\` / `Tools\` package layout remain intact.
