# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.3

HF18.3 fixes the launcher startup crash and the stale legacy-engine selection path reported after HF18.2.

## Launcher startup / ShowDialog

- Fixes PowerShell StrictMode failures from missing legacy/discovery object properties.
- Startup, selection and primary-action callbacks recover/log malformed records instead of tearing down WPF ShowDialog.
- The final packaged UNCANNY.exe is smoke-tested on Windows for launcher survival after opening.

## PCSX2 / old HOME menu migration

- Adds explicit engine-choice tracking with `UserSelected=1`.
- Legacy/unmarked `release-fix.5` preferences are migrated to Automatic/ELYSIUM during install/update and at launch.
- A freshly updated ELYSIUM install can no longer silently swap itself back to the preserved Lucid 2.5 bundle unless the current user explicitly selected Lucid.
- The migration is executed in the Windows regression suite and must return current ABI 143.

## Branding

- Uses a native vector purple/green ELYSIUM emblem in the launcher badge, avoiding poster/raster crop and positioning failures.

## Package

- Preserves the HF18.2 clean public root with implementation PowerShell under `runtime\` and maintenance commands under `Tools\`.
- `UNCANNY.exe` remains the root entry point.
