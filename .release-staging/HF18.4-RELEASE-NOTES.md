# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.4

HF18.4 fixes the launcher no-start regression reported after HF18.3.

## Launcher startup

- Restores reliable startup when Windows PowerShell execution policy is restrictive.
- The native `UNCANNY.exe` launches only its child PowerShell bootstrap with process-scoped `ExecutionPolicy Bypass`.
- UNCANNY does **not** change persistent CurrentUser/LocalMachine execution policy.
- UNCANNY does **not** disable Microsoft Defender or SmartScreen.
- If the launcher child still exits, the native EXE now reports the failure instead of silently disappearing.

## Preserved fixes

- Installed-game/cache/manual path handling remains StrictMode-safe.
- Official cropped silver UNCANNY U PNG remains the launcher badge.
- Stale/unmarked Lucid preferences still migrate to Automatic/ELYSIUM.
- Universal API Bridge, D3D11 stabilization, PCSX2, REVENANT, rollback, and HF18 rendering behavior are preserved.
- Updater hotfix ordering matches package `updateSerial` semantics.

## Windows trust note

HF18.4 is still unsigned. Windows SmartScreen may continue to show an Unknown Publisher / Windows protected your PC warning until UNCANNY is Authenticode-signed with a trusted code-signing identity. This hotfix fixes the **no-launch after approval** failure; it does not bypass or suppress Windows security prompts.
