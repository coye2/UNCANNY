# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.5

HF18.5 repairs the launcher/library failures reproduced after HF18.4.

## Fixed from the tester evidence

- **Scan PC / startup scan:** the packaged scanner resolves its PowerShell dependencies from `runtime\`, where those scripts actually ship.
- **Library handoff:** cached, manually added, and scanned records are canonicalized through guarded property access before WPF binding. Legacy `Path`, `Exe`, missing optional fields, and malformed records no longer blank the list.
- **Manual Add Game is authoritative:** a user-selected EXE is no longer dropped on a later scan by heuristic helper/launcher filtering. UNCANNY's own internal executables remain blocked.
- **Official logo:** the shipped 64×64 RGBA asset is derived from the exact Library file `Monochrome Circular U Emblem(1).png`. No vector redraw or generated substitute is used.
- **WPF logo decoding:** the packaged official PNG passes the Windows WPF decode gate, and the launcher also converts through a 32-bit ARGB surface before display.
- **Diagnostics:** recovered cache/render/scan failures now include stack and invocation-position evidence.
- **Startup:** HF18.4's process-scoped PowerShell-policy recovery remains intact.
