# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.6

HF18.6 is a focused installer/update performance and PCSX2 launch repair based on real tester evidence.

## Fixed

- Removes duplicate full release-binary verification during normal game install/update.
- Uses streaming PE header/import inspection for architecture checks instead of loading whole binaries into memory.
- For 32-bit games, validates only the required isolated x64 neural helper/bridge route instead of re-verifying the entire x64 runtime set.
- Carries the verified original-game SHA-256 forward through the transaction so the same large game EXE is not repeatedly hashed.
- Compares planned installed files against the new package and skips byte-identical files entirely.
- Same-build healthy updates now take a verified no-op fast path instead of rebuilding the full transaction.
- Reuses an already verified neural asset core when its pinned hashes match instead of unpacking/re-hashing the same package again.
- Provider discovery now prefers a bounded installed-target fast path and stops once the required roles are found.
- Creates rollback backups only for files that actually change.
- Keeps staged-temp verification, current-destination verification, atomic replacement and committed-destination verification for changed files.
- Adds real progress sub-stages through the formerly opaque 24–95% range.

## PCSX2 launch repair

- Normal ELYSIUM installs no longer run an unnecessary engine-switch transaction before PCSX2 can open.
- Optional REVENANT proof recovery is bounded and fail-open; it can no longer prevent PCSX2 from starting.
- PCSX2 runtime attachment uses a shorter bounded startup budget so the emulator is not held suspended for a long pre-window wait.
- If optional attachment/engine preparation is unconfirmed, the emulator is allowed to resume instead of being blocked.
- Packaged acceptance now verifies that the installed PCSX2 wrapper starts the verified original executable and successfully loads/initializes the UNCANNY runtime.

## Preserved

HF18.5 Scan PC/runtime-root repair, cache/manual/scan normalization, authoritative Add Game retention, official Library logo, startup-policy recovery, rollback, Universal API Bridge and HF18 rendering behavior remain preserved.
