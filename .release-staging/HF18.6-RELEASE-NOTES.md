# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.6

HF18.6 is a focused installer/update performance hotfix based on tester evidence from real game updates.

## Fixed

- Removes duplicate full release-binary verification during normal game install/update.
- Uses streaming PE header/import inspection for architecture checks instead of loading whole binaries into memory.
- For 32-bit games, validates only the required isolated x64 neural helper/bridge route instead of re-verifying the entire x64 runtime set.
- Carries the verified original-game SHA-256 forward through the transaction so the same large game EXE is not repeatedly hashed.
- Compares planned installed files against the new package and skips byte-identical files entirely.
- Creates rollback backups only for files that actually change.
- Keeps staged-temp verification, current-destination verification, atomic replacement and committed-destination verification for changed files.
- Adds real progress sub-stages through the formerly opaque 24–95% range so updates no longer appear frozen at 27% or 70%.

## Preserved

HF18.5 Scan PC/runtime-root repair, cache/manual/scan normalization, authoritative Add Game retention, official Library logo, startup-policy recovery, PCSX2, REVENANT, rollback, Universal API Bridge and HF18 rendering behavior remain preserved.

## Release gate

HF18.6 is published only from the exact candidate that passes:

- static/regression suite
- x86/x64 production + Engine 4.5 acceptance builds
- Windows HLSL compilation
- D3D11 WARP rendered-quality validation
- launcher/install/rollback regressions
- packaged HF18.6 game install/update speed regression
- packaged official-logo/cache validation
- packaged scanner execution
- normal packaged launcher startup
- AllSigned packaged launcher startup
- exact ZIP hash/extraction
- Microsoft Defender ZIP + extracted-tree scan

UNCANNY remains unsigned, so SmartScreen / Unknown Publisher can still appear until trusted Authenticode signing is configured.
