# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.7

HF18.7 is a launch/runtime compatibility repair built from the exact CI-green candidate that passed the complete Windows package gate.

## Universal launch repair

- Replaces wrapper-in-place executable replacement with a verified **UNCANNY.Launch.exe sidecar**.
- Keeps the selected game/emulator executable at its original filename and preserves its bytes.
- Validates the target SHA-256 and sidecar SHA-256 before launch.
- Migrates legacy wrapper-in-place installs transactionally back to the real target filename.
- Preserves original working directory and forwarded arguments.
- Packaged acceptance verifies untouched PCSX2 and generic target launch through the sidecar.

## D3D11 startup and hard-lock repair

- Keeps shader compilation and D3D11 neural/provider initialization off the game's Present path.
- Present uses non-blocking ownership and falls open to the native game frame while maintenance work is active.
- Re-arms a native-only stabilization window after resize, fullscreen, target-mode and color-space transitions.
- Defers temporal/neural work during the D3D11 transition ramp instead of risking a startup or splash-screen stall.
- Adds a subtle click-through **Press HOME to open** startup hint without adding D3D work.

## PCSX2 / OneDrive profile repair

- Supports PCSX2 profiles stored under OneDrive/Cloud Files without treating normal cloud placeholders as unsafe links.
- Continues blocking true symlinks, junctions and other name-surrogate redirects.
- Preserves automatic, transactional REVENANT texture-replacement configuration and rollback.
- Retains the HF18.6 verified same-build fast update path and neural-core reuse.

## Launcher/library repair

- Recovers UNCANNY-Library.ps1 from a duplicated-tail corruption and reapplies only the intended HF18.7 sidecar install/integrity logic.
- Manual Add Game, scan/cache normalization and existing HF18.5/HF18.6 launcher behavior remain preserved.
- Sidecar installs are marked stale if the target or launcher bytes no longer match the recorded SHA-256.

## Release gate

The exact published ZIP passed:

- static/regression contracts
- x86/x64 production and Engine 4.5 acceptance builds
- package boundary and SHA-256 audit
- Windows HLSL compilation
- D3D11 WARP rendered slider/quality matrix

- Cloud Files vs symlink/junction reparse classification
