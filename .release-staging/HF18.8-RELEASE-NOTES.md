# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.8

HF18.8 is a stabilization hotfix focused only on the two launch failures reproduced from the HF18.7 user logs.

## Post-install state repair

- Fixes valid sidecar installs being marked **UPDATE** again immediately after a successful install.
- Accepts Windows CRLF line endings when validating recorded target and sidecar SHA-256 values.
- A verified same-build install now remains current instead of re-running the installer on every click.
- Preserves the HF18.6/HF18.7 fast no-op update path.

## PCSX2 legacy-wrapper recovery

- Detects the poisoned migration state where a sidecar record says PCSX2 is current but `pcsx2-qt.exe` is still byte-identical to the old UNCANNY wrapper.
- Detection requires byte identity with the adjacent legacy `UNCANNY.NativeLauncher.exe`; it does not guess from filenames alone.
- Transactionally restores the preserved `pcsx2-qt.uncanny-original.exe` as the canonical `pcsx2-qt.exe`.
- Keeps the normal HF18.7 verified `UNCANNY.Launch.exe` sidecar architecture after recovery.
- OneDrive/Cloud Files PCSX2 profile support and transactional REVENANT configuration remain preserved.

## Library integrity repair

- Rebuilt `UNCANNY-Library.ps1` from the known-clean HF18.7 baseline after validation caught an intermediate corruption.
- Reapplied only the HF18.8 installed-state and legacy-PCXS2 recovery deltas.
- No rendering, shader, Control Deck, scanner, or feature expansion was added in this hotfix.
