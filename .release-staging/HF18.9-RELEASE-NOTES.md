# UNCANNY v0.20.0-alpha.1 — ELYSIUM Engine 4.5 — HF18.9

HF18.9 is a stability and route-recovery hotfix based on two real hardware findings: Fallout 4's D3D11 safe path works, Stray reproduces the same hard-lock class, and PCSX2's previously working UNCANNY/DLSS5 path is Direct3D 12 rather than D3D11.

## Universal direct-D3D11 stability floor

- Removes the Fallout-only D3D11 safety exception.
- Every direct D3D11 title now uses the proven current-frame ELYSIUM compatibility floor after native Present stabilization.
- Native-depth acquisition, temporal history/flow and D3D11 neural interop remain deferred on that compatibility floor instead of being allowed to hard-lock a title after startup.
- The game still owns native Present; UNCANNY preprocessing remains optional and fail-open.
- External feeder surfaces retain their separately proven synchronization path.

This is intended to cover the same failure class observed on Fallout 4 and Stray without adding executable-name allowlists.

## PCSX2 D3D12 / Feature-18 route recovery

- Restores the known-good PCSX2 graphics route explicitly: `EmuCore/GS Renderer=15`, which PCSX2 maps to Direct3D 12.
- Applies the renderer setting transactionally to PCSX2's main configuration and existing per-game overrides alongside UNCANNY's REVENANT texture settings.
- Records `PCSX2Renderer=Direct3D12` and `PCSX2RendererValue=15` in the UNCANNY launch record.
- Same-build verification now treats PCSX2 renderer drift away from D3D12 as stale so an update can repair the route instead of claiming the install is current.
- The existing native D3D12/Feature-18 execution stack remains preserved; HF18.9 does not replace it with the D3D11 fallback.
- HF18.8's sidecar launch, OneDrive/Cloud Files profile support, legacy-wrapper recovery and transactional rollback remain preserved.
