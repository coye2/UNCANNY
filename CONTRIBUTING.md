# Contributing

UNCANNY is in alpha. The most useful contribution right now is a bug or compatibility report that can actually be reproduced.

Please include:

- game/emulator and version
- executable
- graphics API
- x86/x64
- GPU and driver
- UNCANNY version
- what you expected
- what happened
- steps to reproduce
- status/log output if available
- screenshot or video for visual issues

If you're testing the neural route, say whether you only saw the provider load or whether current neural output was actually visible. Those are different things.

Do not post private source/workspace archives, secrets, personal paths or sensitive logs in public issues.

For security reports, see [SECURITY.md](SECURITY.md).
