# contributing

The most useful help right now is a bug report I can actually reproduce.

Please include:

- game/emulator + version
- executable
- graphics API
- x86/x64
- GPU + driver
- UNCANNY build
- what you expected
- what happened
- exact steps
- status/log output
- screenshot/video if it is visual

If you are testing REVENANT, say whether the texture was only generated or whether you actually saw the replacement in the game.

If you are testing the neural bridge, say whether the provider only loaded or whether evaluations/output were actually being used.

Those are different levels of proof.

Do not post private source archives, tokens or personal paths/log data.

For security issues, see [SECURITY.md](SECURITY.md).
