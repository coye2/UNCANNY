UNCANNY

Universal DLSS 5 Neural Remaster Engine for PC Games and Emulators.

UNCANNY is an independent Windows real-time remaster middleware project combining DLSS 5 / Feature-18 neural rendering, adaptive Clean reconstruction stages, Motion Guard, Ghosting Guard, REVENANT persistent asset reconstruction, legacy-game compatibility, diagnostics and rollback.

What makes UNCANNY different?

A feeder or injector normally handles one part of the pipeline. UNCANNY is being built as the complete user-facing remaster stack: API attachment, neural transport, real Feature-18 evidence, deeper reconstruction, motion protection, persistent asset rebuilding, controls, compatibility reporting and safe rollback.

Core systems

  • DLSS 5 neural rendering with create/evaluate/return/present evidence.
  • Clean 1–3 adaptive neural reconstruction depth.
  • Motion Guard + Ghosting Guard for temporal stability.
  • REVENANT persistent asset reconstruction.
  • Legacy compatibility including 32-bit/x86 neural-helper work.
  • Control Deck, diagnostics, backups and rollback.

DLSS 5 tools and feeders

If you are comparing UNCANNY with DLSS5-Feeder, RenoDX/ShortFuse, OptiScaler, Deep Fried Chicken or RTX Remix, see the project's DLSS 5 tools and feeders overview. It explains where UNCANNY overlaps and where its remaster-engine scope differs.

Compatibility

Direct3D 12 is currently the strongest native PC path. D3D11, D3D10 and D3D9 compatibility work is implemented to different evidence levels. PCSX2 is a primary emulator target. Vulkan/OpenGL are not yet at DirectX parity.

FAQ

Is UNCANNY a DLSS5 feeder? It includes feeder/transport-style compatibility work, but its scope is broader: neural rendering, Clean reconstruction, motion protection, REVENANT, controls, diagnostics and rollback.

Is UNCANNY just ReShade? No. The current product includes native runtime components, x86/x64 interoperability, an x64 neural helper, Control Deck, REVENANT workers and installer/rollback systems. Some compatibility routes may interoperate with third-party components internally.

Does UNCANNY work with PCSX2? PCSX2 is one of the primary targets and one of the most-developed environments; final neural REVENANT rendered-use acceptance remains in progress.
