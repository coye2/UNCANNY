what STRATA is doing

  • one launcher/library instead of a pile of separate entry points
  • real-time STRATA reconstruction + motion protection
  • REVENANT captured asset reconstruction and saved texture packs
  • optional neural provider paths
  • repair/remove/restore that tracks what UNCANNY actually owns

current preview status

PCSX2 has the strongest REVENANT saved-pack path right now. Native D3D9 REVENANT can capture real game textures and build validated replacement assets, but the latest Deadpool run did not finish the visible replacement A/B. I am not calling that last stage proven yet.

The neural bridge has real provider create/evaluate/output-use evidence on D3D9, D3D11 and D3D12. Vulkan, OpenGL and AMD are still being finished.

install

  1. download a build from Releases
  2. extract the whole ZIP
  3. run UNCANNY.exe
  4. add/scan your game
  5. install/update UNCANNY
  6. press Home in-game for Control Deck
