UNCANNY

Real-time remaster engine for PC games and emulators.

UNCANNY combines ELYSIUM multi-pass reconstruction, Adaptive Realism, Motion Guard, Ghosting Guard, REVENANT persistent asset reconstruction, legacy DirectX compatibility, diagnostics, rollback and optional DLSS 5 integration.

HF18.1

HF18.1 fixes the installer/update preflight that could appear stuck at 2%, adds real 3/4/5/6/7% progress, fixes updater-button clipping, and uses the current full-color ELYSIUM emblem. HF18 rendering and Universal API Bridge behavior is preserved.

Adaptive Realism

Engine 4.5 introduces a scene-aware UNCANNY-native remaster layer with five live levels: OFF / LOW / BALANCED / HIGH / INSANE. Adaptive Realism is separate from the DLSS 5 provider path and can run without DLSS 5.

Tier A
Trustworthy depth + native motion.
Tier B
Trustworthy depth + UNCANNY optical flow.
Tier C
Depth only; conservative spatial lighting.
Tier D
No trustworthy depth; tonal/spatial fallback.

D3D11 currently has the strongest Adaptive Realism route. D3D12 and D3D9 remain supported with conservative fallback when trustworthy scene depth is unavailable.

Motion-first reconstruction

  • Motion Guard and Ghosting Guard remain authoritative.
  • Temporal history is reduced when motion confidence, depth continuity or history agreement fails.
  • X2.5 deliberately uses the lowest temporal-history weight for cleaner motion.
  • ENABLE UNCANNY OFF remains the master bypass.
  • UNCANNY pass depth remains separate from DLSS 5 pass depth.

Core systems

  • ELYSIUM reconstruction with live 1 / 1.5 / 2 / 2.5 / 3 pass-depth control.
  • Adaptive Realism with scene-aware lighting/detail/tonal response.
  • Motion Guard + Ghosting Guard for temporal stability.
  • REVENANT experimental persistent asset reconstruction.
  • DLSS 5 integration as a separate optional NVIDIA neural route.
  • Control Deck, diagnostics, backups and rollback.

Release verification

The exact Engine 4.5 package passed the full regression suite, 22 compiled Engine 4.5 checks, x86/x64 Adaptive Realism tests, production builds, strict package/integrity audits, dynamic install/rollback testing and Microsoft Defender scans of both the extracted package and completed ZIP with 0 detections.

The package does not bundle paid/restricted Marty McFly / Pascal Gilcher shader source or binaries.

Compatibility

D3D11 is the strongest current Adaptive Realism path. D3D12, D3D10/10.1 and D3D9 remain supported to different capability levels. PCSX2 is the primary emulator acceptance target. Vulkan/OpenGL have conservative lifecycle/presentation compatibility observation; full ELYSIUM/neural parity is not claimed.

Build/CI validation does not replace real-game visual/performance testing across specific NVIDIA, AMD and Intel GPUs.
